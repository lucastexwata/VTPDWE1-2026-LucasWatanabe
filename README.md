# Meu Site Pessoal

Esse é um projeto desenvolvido para um dos praticandos de DWE1, com o
objetivo de colocar em prática os conhecimentos de HTML, Git e GitHub.

Aqui apresento um pouco sobre quem eu sou, minha cidade, meus sonhos,
uma pessoa que me inspira e algumas coisas que fazem parte da minha vida,
como músicas, filmes, livros e hobbies.

O site também possui imagens, links externos, navegação entre páginas,
âncoras internas e um mapa do Google Maps.
